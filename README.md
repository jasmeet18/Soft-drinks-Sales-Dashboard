# 🥤 Soft-Drinks Sales Dashboard (Power BI)

This Power BI dashboard provides a comprehensive and interactive visualization of soft-drink sales performance across different products, regions, and months. It enables users to explore key insights with slicers, KPIs, and dynamic charts.

## 🚀 Features

- Product-wise sales performance
- Region-wise distribution
- Monthly trends
- Dynamic filtering based on drink selection
- Insightful KPIs to drive business decisions

## 📁 File

- `PowerBI Sales Dashboard.pbix` – Power BI file containing the entire dashboard with filters and visuals.

## 📣 How to Use

1. Open the `.pbix` file in Power BI Desktop.
2. Click on any drink name in the visuals or slicers.
3. Watch the entire dashboard adapt to show relevant data.
4. Hover over charts for tooltips and explore detailed insights.
